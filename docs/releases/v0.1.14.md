Note for iPad v0.1.14 — 노트에서 원하는 페이지만 골라 새 노트로 만드는 업데이트입니다.

## 설치

`NoteApp-0.1.14.ipa`는 서명되지 않은 IPA입니다. 이전처럼 `xtool install NoteApp-0.1.14.ipa`(또는 Sideloadly · AltStore)로
설치하면 데이터는 그대로 유지됩니다.

## 바뀐 점

- **선택한 페이지로 새 노트 만들기**: PDF를 불러온 노트(또는 어떤 노트든)에서 필요한 페이지만 골라 별도의 노트로 만듭니다.
  - 시작: 페이지 추가 메뉴(＋ 문서 아이콘) › **페이지를 골라 새 노트로**, 또는 페이지 목록에서 썸네일을 길게 눌러 **선택해서 새 노트로**
  - 페이지 목록에서 썸네일을 탭해 선택/해제(체크 표시), **모두**로 전체 선택, **취소**로 끝내기
  - **새 노트로**를 누르면 제목(기본: `<노트 제목> 3–5, 8쪽`)을 정해 이 노트와 같은 폴더에 만들고, 바로 열 수 있습니다
  - 필기 · 텍스트 · 이미지 · 종이 · 책갈피가 그대로 옮겨지고, 페이지 순서는 원래 노트의 순서를 따릅니다
  - PDF 배경은 **선택한 페이지만 담은 PDF**로 새 노트에 들어가서 새 노트의 용량이 작습니다
  - 원래 노트는 바뀌지 않습니다

노트 파일 형식은 바뀌지 않아 Android 앱과 같은 NAS 폴더를 그대로 함께 쓸 수 있습니다.
