Note for iPad v0.1.9 — 사진 위에도 펜으로 쓸 수 있게 고친 업데이트입니다(Android v0.1.12와 같은 수정).

## 설치

`NoteApp-0.1.9.ipa`는 서명되지 않은 IPA입니다. 이전처럼 `xtool install NoteApp-0.1.9.ipa`(또는 Sideloadly · AltStore)로
설치하면 데이터는 그대로 유지됩니다.

## 고침

- **사진 위에 필기**: 페이지에 넣은 사진이 필기를 가려 사진 위에 쓴 글씨가 보이지 않던 문제를 고쳤습니다.
  이제 펜 · 형광펜 필기는 항상 맨 위에 그려지고, 사진은 종이와 필기 사이에 놓입니다.
  - 사진을 옮기거나 크기를 바꾸는 동안에만 사진이 위로 떠오르고, 손을 떼면 다시 필기 아래로 들어갑니다.
  - 지우개는 사진 위의 필기만 지우고 사진은 그대로 둡니다.
  - 썸네일 · 페이지 이미지 공유 · PDF 내보내기도 같은 순서(종이 → 사진 → 필기 → 텍스트 상자)로 그립니다.

노트 파일 형식은 바뀌지 않아 Android 앱과 같은 NAS 폴더를 그대로 함께 쓸 수 있습니다.
