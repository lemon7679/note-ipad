Note for iPad v0.1.6 — Android 앱 v0.1.1~v0.1.6의 업데이트를 iPad에 모두 반영한 업데이트입니다. 버전 번호도 Android와 맞췄습니다
(같은 번호 = 같은 기능 수준). 엔진은 note-core InkEngine 0.2.0입니다.

## 설치

`NoteApp-0.1.6.ipa`는 서명되지 않은 IPA입니다. 이전처럼 `xtool install NoteApp-0.1.6.ipa`(또는 Sideloadly · AltStore)로
설치하면 데이터는 그대로 유지됩니다.

## 새 기능

- **이 iPad → NAS로 이동**: 라이브러리에서 이 iPad에 있는 PDF(그 밖의 파일 포함)의 이동을 누르면 "NAS로 옮기기" 아래에
  연결된 NAS와 그 폴더들이 함께 나옵니다. 고른 NAS 폴더로 옮겨지고 다음 동기화 때 NAS에 올라갑니다. 복사가 끝까지 된 것을
  확인한 뒤에만 원본을 지우며, 최근 문서 · 즐겨찾기도 따라갑니다.
- **낙서로 지우기**: 펜으로 지우고 싶은 글씨 위를 여러 번(왕복 5회 정도) 문지르면 지우개로 바꾸지 않아도 그 아래 필기가
  지워집니다. 낙서 자체는 남지 않고 실행 취소 한 번으로 되돌릴 수 있습니다. 빈 곳의 지그재그나 "m"처럼 둥글게 꺾이는 글씨는
  그대로 필기로 남습니다. 설정 › 필기 또는 편집기 ⋯ 메뉴에서 끌 수 있습니다(기본 켜짐, 형광펜에는 적용되지 않음).

## 필기 · 렌더링

- **연필이 더 자연스럽고 부드러워졌습니다**: 흑연이 획을 따라 밀도로 쌓여 가장자리가 부드럽고, 같은 곳을 다시 그으면 진해집니다.
  종이 결도 벨벳 같은 질감으로 바뀌었습니다(예전 필기도 새 질감으로 보이며 파일은 그대로).
- **정밀 지우개가 닿은 부분만 지웁니다**: 예전에는 조금만 닿아도 그 구간의 획 폭 전체가 지워졌습니다(굵은 형광펜에서 특히 심함).
  완전히 지운 부분은 획 데이터에서도 잘려 올가미에 잡히지 않고, 획 지우개는 남은 잉크에 닿아야 지웁니다.
  PDF 내보내기에도 지운 부분이 그대로 반영됩니다.
- **형광펜이 많은 페이지에서도 확대·축소, 스크롤, 지우개가 끊기지 않습니다**
  - 새 엔진의 잉크 래스터화가 형광펜이 겹친 페이지에서 20~100배 빠릅니다.
  - 스크롤 · 확대용 페이지 타일과 미리 보기를 작업 스레드에서 그립니다(화면 가운데부터, 그동안 이전 타일을 늘려 보여 줌).
  - 확대 배율을 약 1.26배 간격 단계로 나눠, 조금만 핀치해도 모든 타일을 다시 그리던 것을 없앴습니다.
  - 지우개로 지운 영역을 터치 이벤트마다가 아니라 화면 갱신마다 한 번만, 바뀐 부분만 다시 그립니다.
- **자동 저장과 표지 썸네일이 필기를 막지 않습니다**: 저장할 내용을 스냅숏으로 잡아 백그라운드에서 직렬화·저장합니다.
  저장 순서는 그대로 보장됩니다(노트를 닫을 때는 진행 중인 저장까지 마친 뒤 닫음).

## 동기화

- 연결이 잠깐 끊기거나 NAS가 바쁠 때(서버 5xx, DSM 402) 전송을 잠시 뒤 최대 두 번 다시 시도합니다.
- 동기화 오류에 파일 이름만이 아니라 경로(`선형대수.inknote/document.json`)를 보여 주고, DSM이 알려 준 세부 정보를 덧붙입니다.
  400~404 File Station 오류도 뜻을 풀어 표시합니다.
- DSM이 업로드의 수정 시각(`mtime`) 필드를 거부하면 그 필드 없이 다시 올리고, 이후로는 보내지 않습니다.

## 고침

- **이동 화면의 아이콘**: 저장소 맨 위 줄과 폴더가 모두 폴더 아이콘이라 이 iPad와 NAS가 구분되지 않았습니다. 이제 이 iPad는
  iPad, NAS는 종류별 아이콘(Synology: 서버, WebDAV: 지구본, SMB · 파일 앱: 네트워크 드라이브)으로 보입니다.

## Android에만 있는 것

- GPU(OpenGL ES) 렌더링은 Android 전용입니다. iPad의 Metal 렌더러는 다음 단계입니다.
- 확대·이동 제스처 인식 수정(Android v0.1.1)과 백그라운드 동기화 중단(v0.1.4)은 Android 고유 문제라 iPad에는 해당하지 않습니다
  (iPad는 시스템 스크롤 뷰를 쓰고, 백그라운드 진입 시 시스템이 허락한 시간 안에 동기화를 마칩니다).

노트 파일 형식은 그대로라 Android 앱과 같은 NAS 폴더를 함께 쓸 수 있고, 정밀 지우개로 지운 자리도 두 앱에서 똑같이 보입니다.

## 이 빌드에 대해

- GitHub Actions(macOS)에서 note-core와 함께 빌드했고, 같은 커밋을 CI가 iPad 시뮬레이터에서 실제 엔진으로 실행해 라이브러리 ·
  편집기 · PDF · NAS 연결 · 설정 화면을 확인했습니다. 동기화 · NAS 클라이언트 · 낙서 인식 · PDF 지운 영역 파싱은 Linux 테스트로 검증합니다.
- 실제 iPad · Apple Pencil · 실제 NAS에서는 아직 손으로 검증하지 않았습니다. 문제가 있으면 이슈로 알려 주세요.
