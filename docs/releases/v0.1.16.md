Note for iPad v0.1.16 — 노트 화면의 모든 메뉴를 숨기고 페이지만 보는 전체 화면을 추가한 업데이트입니다.

## 설치

`NoteApp-0.1.16.ipa`는 서명되지 않은 IPA입니다. 이전처럼 `xtool install NoteApp-0.1.16.ipa`(또는 Sideloadly · AltStore)로
설치하면 데이터는 그대로 유지됩니다.

## 바뀐 점

- **메뉴 숨기기(전체 화면)**: 상단 바의 새 버튼(페이지 목록 · 책갈피 · 검색 옆)이나 **더 보기 › 메뉴 숨기기 (전체 화면)**를 누르면
  상단 바 · 도구 줄 · 페이지 목록 · 쪽 번호 · 도형 안내, 그리고 상태 막대와 홈 표시기까지 숨기고 페이지만 화면 가득 보여 줍니다.
  - 오른쪽 위의 작고 옅은 버튼을 누르면 메뉴가 다시 나타납니다
  - 숨긴 상태에서도 Pencil 더블 탭 · 스퀴즈 도구 팔레트로 도구 · 굵기 · 색을 바꾸고 실행 취소할 수 있습니다.
    팔레트에서 펜 설정을 열면 메뉴가 다시 나타납니다
  - 노트를 새로 열면 항상 메뉴가 보이는 상태로 시작합니다

노트 파일 형식은 바뀌지 않아 Android 앱과 같은 NAS 폴더를 그대로 함께 쓸 수 있습니다.
