Note for iPad v0.1.8 — 노트를 옆으로 넘겨 보는 페이지 넘기기, Apple Pencil 버튼으로 여는 휠 메뉴, 새 노트 크기 직접 입력을 더한 업데이트입니다(Android v0.1.11과 같은 기능 수준).

## 설치

`NoteApp-0.1.8.ipa`는 서명되지 않은 IPA입니다. 이전처럼 `xtool install NoteApp-0.1.8.ipa`(또는 Sideloadly · AltStore)로
설치하면 데이터는 그대로 유지됩니다.

## 새 기능

- **옆으로 넘기기**: 한 화면에 한 페이지씩 보이고, 손가락으로 옆으로 밀면 다음/이전 페이지로 넘어갑니다.
  - 살짝 튕기면 한 장씩 넘어가고, 천천히 끌다 놓으면 더 많이 보이는 페이지에 맞춰 멈춥니다.
  - 페이지는 화면에 통째로 들어오게 맞춰지고, iPad를 돌리거나 Split View로 크기가 바뀌면 다시 맞춰집니다.
  - 확대한 상태에서는 그 페이지 안에서 자유롭게 움직이고, 페이지 끝에서 더 밀면 옆 페이지로 넘어갑니다.
  - Apple Pencil은 지금처럼 바로 쓰고, 손가락으로 그리기 모드에서는 두 손가락으로 넘깁니다.
  - 노트 화면의 더 보기(⋯) › "옆으로 넘기기", 또는 설정 › 필기 › "페이지 넘기기"(세로 스크롤 · 옆으로 넘기기)에서 바꿉니다.
    기본값은 지금처럼 세로 스크롤입니다.
- **펜 버튼 휠 메뉴**: Apple Pencil 2세대를 두 번 탭하거나 Apple Pencil Pro를 쥐면(스퀴즈) 펜 끝 위치에 원형 메뉴가 열립니다.
  - 바깥 원: 펜 · 형광펜 · 지우개 · 올가미 · 텍스트 · 레이저 · 실행 취소 · 다시 실행 · 펜 설정
  - 안쪽 원: 지금 펜(또는 형광펜)의 색 6가지, 가운데: 누를 때마다 다음 굵기로 바뀝니다.
  - 바깥을 누르면 닫힙니다. 펜 위치를 알 수 없으면 화면 가운데에 열립니다.
  - 설정 › 필기 › "펜 버튼"에서 휠 메뉴(기본) · 지우개 전환(예전 동작) · 사용 안 함을 고를 수 있습니다.
    iPad 설정에서 Pencil 두 번 탭 · 쥐기를 꺼 두면 반응하지 않습니다.
- **새 노트 크기 직접 입력**: 크기에 A4 · B5 · A5 · Letter · 화면과 "직접 입력"이 있습니다. 너비 × 높이를 mm로 넣으며
  한 변은 50–1200 mm입니다. 고른 크기가 "210 × 297 mm"처럼 표시되고 미리보기도 그 비율을 따릅니다.

## 고침

- **다른 앱에서 "Note에서 열기"로 받은 PDF**: 필기 노트로 바뀌지 않고 이 iPad에 PDF 파일로 저장되어 PDF 뷰어로 열립니다.
  이미 이 iPad에 있는 PDF는 복사하지 않고 그대로 엽니다.

노트 파일 형식은 바뀌지 않아 Android 앱과 같은 NAS 폴더를 그대로 함께 쓸 수 있습니다(직접 입력한 크기의 노트 포함).
