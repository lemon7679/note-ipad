Note for iPad v0.1.15 — 펜 버튼 휠을 굿노트의 도구 팔레트처럼 펜 끝을 감싸는 모양으로 다시 만든 업데이트입니다.

## 설치

`NoteApp-0.1.15.ipa`는 서명되지 않은 IPA입니다. 이전처럼 `xtool install NoteApp-0.1.15.ipa`(또는 Sideloadly · AltStore)로
설치하면 데이터는 그대로 유지됩니다.

## 바뀐 점

- **펜 버튼 휠 → 굿노트식 도구 팔레트**: Apple Pencil 버튼(두 번 탭 · 스퀴즈)을 누르면 왼쪽 위 1/4 원 대신
  **펜 끝 바로 옆**에 팔레트가 열립니다. 화면 가장자리에서는 팔레트 전체가 보이도록 안쪽으로 살짝 옮겨집니다.
  - **곡선 도구 막대**: 펜 끝의 왼쪽 위를 감싸는 호에 펜 · 형광펜 · 지우개 · 올가미 · 텍스트 · 레이저. 펜과 형광펜 아이콘에는
    지금 색이 작은 점으로 표시됩니다. 호의 아래쪽 끝에는 **실행 취소**
  - **위쪽 끝의 굵기 · 색 막대**: 굵기 프리셋 3개를 바로 고르고, 오른쪽 **색 점**을 누르면 아래에 모든 색(최근 사용자 색 포함)이 펼쳐집니다
  - **왼쪽 작은 열**: 펜 설정 · 펜 종류(볼펜 · 만년필 · 연필 · 붓펜 · 캘리그라피 · 마커를 펼쳐서 고르기) · 다시 실행
  - 도구나 색을 고르면 닫히고, 굵기 · 펜 종류 · 실행 취소/다시 실행은 팔레트를 연 채로 이어서 쓸 수 있습니다
  - 팔레트 바깥을 누르거나 Pencil 버튼을 한 번 더 누르면 닫힙니다
  - 호를 드래그해 돌리던 방식은 없어지고, 모든 옵션이 한눈에 보입니다

노트 파일 형식은 바뀌지 않아 Android 앱과 같은 NAS 폴더를 그대로 함께 쓸 수 있습니다.
