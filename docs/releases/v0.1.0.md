iPad용 필기 앱 **Note**의 첫 릴리스입니다. NAS(Synology · WebDAV · SMB)에 노트와 PDF를 두고, iPad에서 오프라인으로 쓰다가 양방향으로 동기화합니다. 필기는 [note-core](https://github.com/lemon7679/note-core) InkEngine으로 그립니다.

## 설치

`NoteApp-0.1.0.ipa`는 **서명되지 않은** IPA입니다. 설치할 때 자신의 Apple ID로 서명됩니다.

- **xtool (Windows WSL / Linux / macOS)** — iPad를 USB로 연결한 뒤

  ```bash
  xtool install NoteApp-0.1.0.ipa
  ```

  처음이면 `xtool setup`으로 Apple ID 로그인이 필요합니다. 자세한 설정은 [docs/BUILD_WSL.md](https://github.com/lemon7679/note-ipad/blob/main/docs/BUILD_WSL.md).
- **Sideloadly / AltStore** 등 IPA 사이드로딩 도구도 사용할 수 있습니다.
- 무료 Apple ID로 설치한 앱은 7일마다 다시 설치해야 합니다(데이터는 유지). iPad에서 처음 실행할 때 설정 › 일반 › VPN 및 기기 관리에서 개발자를 신뢰해 주세요. iPadOS 16 이상은 개발자 모드도 켜야 합니다.
- 요구 사항: iPadOS 17 이상, iPad 전용.

## 주요 기능

**NAS 중심 파일 관리**
- Synology DSM(File Station API, 2단계 인증), WebDAV(QNAP · TrueNAS · Nextcloud 등), 파일 앱의 SMB 공유 폴더 연결
- Bonjour로 같은 네트워크의 NAS 검색, 연결 테스트, NAS 폴더 선택, 자체 서명 인증서 고정(TOFU)
- NAS 노트 폴더를 iPad에 미러로 두고 3-way 양방향 동기화: 바뀐 페이지만 전송, 충돌 시 "이 iPad 유지 / NAS 유지 / 둘 다 보관", PDF는 열 때 다운로드, 자동·Wi-Fi 전용 동기화, 대량 삭제 방지 안전장치
- NAS 전체 보기(동기화 폴더 밖 PDF 열람·가져오기), 노트를 닫을 때 필기가 합쳐진 PDF 함께 저장(옵션)
- 폴더 · 이동(끌어서 놓기) · 복제 · 이름 변경 · 즐겨찾기 · 최근 문서 · 검색 · 휴지통

**필기**
- 볼펜 · 만년필 · 연필 · 붓펜 · 캘리그라피 · 마커 · 형광펜, Apple Pencil 필압·기울기, 예측 입력
- 그리고 멈추면 도형, 글씨 보정, 손떨림 보정, 정밀/획 지우개
- 올가미: 이동 · 크기 조절 · 복사/붙여넣기(페이지 간) · 색 변경 · 줄 정렬 · 글씨 다듬기
- 텍스트 상자 · 이미지 · 레이저 포인터, 종이 7종(줄 · 좁은 줄 · 모눈 · 점 · 코넬 · 오선지 · 빈 종이)
- 페이지 목록(끌어서 순서 변경 · 책갈피), 노트 전체 실행 취소, 두 손가락 탭 실행 취소, Pencil 더블 탭 지우개

**PDF**
- PDF 뷰어(목차 · 썸네일 · 검색 · 스크러버), "필기 시작"으로 원본은 그대로 두고 필기 노트 생성
- 벡터 PDF 내보내기, 페이지 이미지 내보내기

## 이 빌드에 대해

- 이 저장소의 GitHub Actions(macOS)에서 note-core와 함께 xtool과 같은 방식으로 묶은 Release 빌드입니다.
- 같은 커밋을 CI가 실제 엔진으로 iPad Pro 11″ 시뮬레이터에서 실행해 라이브러리 · 편집기(엔진이 그린 형광펜 · 만년필 ·
  볼펜 · 연필 획) · PDF 뷰어 · NAS 연결 · 설정 화면이 충돌 없이 뜨는 것을 확인했습니다.
- 동기화 엔진과 NAS 클라이언트(WebDAV 파싱, Synology API, 두 기기 동기화 시나리오)는 테스트 43개로, 필기 엔진은
  테스트 74개로 검증했습니다.
- 실제 iPad · Apple Pencil · 실제 NAS에서는 아직 손으로 검증하지 않았습니다. 문제가 있으면 이슈로 알려 주세요.

## 알려진 한계

- 캔버스는 CPU 타일 렌더러입니다(GPU/Metal 렌더러는 다음 단계).
- SMB는 파일 앱 경유입니다(앱 자체 SMB 클라이언트 없음).
- 한 노트를 두 기기에서 동시에 고치면 노트 단위 충돌로 처리합니다.
