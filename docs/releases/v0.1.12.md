Note for iPad v0.1.12 — 펜 버튼 휠을 왼쪽 위 모서리의 1/4 원으로 바꾸고, 펜 호버 강조를 더 차분하게 다듬은 업데이트입니다.

## 설치

`NoteApp-0.1.12.ipa`는 서명되지 않은 IPA입니다. 이전처럼 `xtool install NoteApp-0.1.12.ipa`(또는 Sideloadly · AltStore)로
설치하면 데이터는 그대로 유지됩니다.

## 바뀐 점

- **펜 버튼 휠 → 왼쪽 위 1/4 원**: Apple Pencil 버튼(두 번 탭 · 스퀴즈)으로 여는 휠이 펜 끝 대신 필기 화면 왼쪽 위
  모서리에 원의 일부(1/4)로만 나타나 페이지를 거의 가리지 않습니다(GoodNotes · 메모 앱 방식).
  - **바깥 줄**: 도구(펜 · 형광펜 · 지우개 · 올가미 · 텍스트 · 레이저), 실행 취소/다시 실행, 펜 설정
  - **가운데 줄**: 지금 펜(또는 형광펜)의 모든 색과 최근 사용자 색
  - **안쪽 줄**: 굵기 프리셋을 바로 고르고, 펜이면 이어서 펜 종류(볼펜 · 만년필 · 연필 · 붓펜 · 캘리그라피 · 마커)
  - 각 줄은 **호를 따라 드래그**하면 돌아가며 더 많은 옵션이 보입니다. 휠을 열면 지금 쓰는 도구 · 색 · 펜 종류가 보이는 위치에서 시작합니다.
  - 모서리의 현재 도구 버튼이나 휠 바깥을 누르면 닫힙니다.
- **펜 호버 강조에서 테두리 제거**: Apple Pencil을 옵션 위에 띄우면 이제 테두리 없이 살짝 커지고 옅은 배경만 표시됩니다.

노트 파일 형식은 바뀌지 않아 Android 앱과 같은 NAS 폴더를 그대로 함께 쓸 수 있습니다.
